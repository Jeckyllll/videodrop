# VideoDrop Lite

Версия для сотрудников: скачивание видео и аудио на Mac, выбор качества и формата, открытие готового файла и бесплатные обновления через GitHub. Аккаунты VideoDrop и управление пользователями не нужны.

## Установка один раз

1. [Скачайте VideoDrop-Lite-mac.zip](https://github.com/Jeckyllll/videodrop/releases/latest/download/VideoDrop-Lite-mac.zip) и распакуйте в постоянную папку на Mac.
2. Откройте **Запустить VideoDrop.command**. Нужен Python 3.10+; для скачивания с YouTube также Node.js 22+ или Deno. При первом запуске устанавливаются зависимости.
3. Для видео внутри уроков откройте в Chrome `chrome://extensions`, включите **Режим разработчика**, нажмите **Загрузить распакованное расширение** и выберите папку `extension` внутри **этой копии Lite**. Закрепите VideoDrop Lite в панели Chrome.

Дальше вставьте ссылку в приложение либо откройте урок → VideoDrop Lite → выберите найденное видео. Выберите разрешение и MP4/MKV/MP3/M4A → **Скачать**. Готовые файлы появятся в папке «Загрузки» внутри приложения; кнопка **Открыть видео** запускает файл.

Для авторизованных уроков используется ваш вход на сайт в Chrome. Передача доступа и поиск потоков включаются отдельно. DRM не поддерживается; используйте материалы, доступные вашему аккаунту и разрешённые для скачивания.

## Обновления

Обновления включены автоматически. Lite проверяет опубликованные версии при запуске и затем раз в 6 часов (с кешем), дожидается завершения скачиваний и перезапускает приложение. В разделе **Обновления VideoDrop Lite** есть ручная проверка и возврат к предыдущей версии. Настройки, история и скачанные файлы сохраняются. Входить в GitHub и устанавливать Git не нужно.

Lite получает только пакет **VideoDrop-Lite-mac.zip**. Полная версия не устанавливается поверх Lite ни обновлением, ни откатом. При изменении расширения нажмите **↻** на его карточке в `chrome://extensions`; повторно выбирать папку не нужно.

## Локальные файлы

В Lite нет отправки на Google Диск, YouTube или другое облако, подключения канала и автоматического удаления готовых файлов. Модули управления YouTube Studio отсутствуют в комплекте, расширение не запрашивает разрешение «Отладчик». Прямые запросы к API отправки также отклоняются.

В программе нет данных владельца: каждый Mac создаёт свой локальный ключ. Не пересылайте другим людям уже запущенную личную папку приложения — используйте чистый ZIP по ссылке выше.

Lite открывается по адресу `http://127.0.0.1:8766/`. Полная версия использует другой локальный адрес, поэтому они не подменяют друг друга на одном Mac. Для продолжения скачивания компьютер и локальное приложение должны оставаться включёнными.
