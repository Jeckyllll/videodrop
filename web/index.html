Видео из закрытого урока

Откройте урок в Chrome и нажмите расширение VideoDrop. Оно найдёт встроенные плееры и передаст выбранное видео сюда.

Если плеер не найден, в расширении нажмите «Найти потоки», затем запустите видео.

Видео внутри урока?

Кнопка в Chrome найдёт его на открытой странице.

Один раз подключите расширение

  1. Откройте в Chrome chrome://extensions и включите «Режим разработчика».
  2. Нажмите «Загрузить распакованное расширение» и выберите эту папку:
  3. Закрепите VideoDrop в панели расширений. Откройте урок → VideoDrop → выберите видео.

По умолчанию расширение читает только страницу, на которой вы его открыли. Поиск потоков и передача входа включаются отдельно. DRM не поддерживается.

Обновления VideoDrop

Проверяем настройки…

Обновите расширение: откройте chrome://extensions и нажмите ↻ на карточке VideoDrop. Папку выбирать заново не нужно.

Настройки и видео сохраняются. Версии на GitHub ↗
